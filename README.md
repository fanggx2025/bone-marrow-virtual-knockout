# scRNA virtual knockout of human bone-marrow stroma in osteoarthritis

Code release for the manuscript **"Single-cell virtual knockout identifies PPARG,
HIF1A and RUNX1 as negative regulators of human osteogenesis."**

Gongxi Fang, Jingchao Wang*, Shujun Ren, Yilin Zhang, Baiqing Wang
First Affiliated Hospital of Heilongjiang University of Chinese Medicine /
Heilongjiang Academy of Chinese Medical Sciences
*Corresponding author: 15046058911@163.com

## What this repository contains

The full analysis pipeline behind the manuscript:

1. **S01-S02** `scripts/build_s01_s02.R` - atlas loading, QC, stromal gating,
   Harmony integration, clustering and five-subtype annotation
   (10,206 stromal cells from 20 donors).
2. **S03** pseudotime trajectory - `scripts/91_candidate_genes.R` (Monocle2 DDRTree,
   rooted at CXCL12+/KITLG+ progenitors).
3. **S04** in-silico virtual knockout (scTenifoldNet/scTenifoldKnk v1.0.3) -
   `scripts/90_calibrate_knk.R`, `92_run_s04_pilot.R`, `94_run_s04_full.R`,
   `93_rescore_s04.R`.
4. **S05/S05b** compound-target mapping (ChEMBL + literature supplement) -
   `scripts/20_tcm_compounds.py`, `21_wuweizi_etcm_supplement.py`.
5. **S06** three-way consensus - `scripts/95_consensus.R`.
6. **S07** osteoarthritis disease-state validation - `scripts/s07_oa_validation.R`.
7. **Docking** (AutoDock Vina 1.2.7, chain-A 2PRG protocol) -
   `scripts/21-30_*.py` (SwissDock AC/EADock 2.0 web submissions were performed
   manually and parsed by `scripts/28*_parse*.py`).
8. **Figures 1, 6, 7** - `scripts/s09_fig1_overview.R`, `s08_fig6_consensus.R`,
   `s07b_fig7_figures.R`.

## Data provenance (important)

- The single-cell data were **not** generated by the authors. All analyses used the
  **CELLxGene Discovery "Bone Marrow Reference" atlas**
  (dataset `b6037d0f-c415-45f7-8d01-0e69407fba9c`, accessed 2026-10-08), a curated
  collection of 117,308 human bone-marrow cells assembled from published GEO series:
  normal arm GSE190965 / GSE169396 / GSE202813; osteoarthritis arm GSE147390 /
  GSE196678. The atlas contains no fracture samples.
- All **derived analysis outputs** (knockout scores, consensus targets, docking
  panels, OA validation) are archived at **Zenodo (doi:10.5281/zenodo.23684945)**
  and are also Supplementary Tables S1-S13 of the manuscript.
- This repository intentionally contains **no primary or intermediate data**
  (see `.gitignore`). Download the atlas from CELLxGene
  (`scripts/02_download_matrix.sh b6037d0f-c415-45f7-8d01-0e69407fba9c bone_marrow_ref`)
  and place it at `data/raw/bone_marrow_ref.h5ad`.

## Reproducibility notes (please read)

- **S01-S02 were originally built interactively in RStudio.** The script
  `build_s01_s02.R` reimplements the documented Methods procedure; borderline
  cell assignments may differ slightly from the interactive build. The exact
  objects used for the manuscript tables are recoverable from the archived
  derived tables (Zenodo) plus this script.
- The disease axis is **osteoarthritis vs normal**, and disease status is
  perfectly collinear with source study (OA = GSE147390+GSE196678;
  normal = GSE190965+GSE169396+GSE202813). This limitation is stated in the
  manuscript (Limitations, item a).
- The docking scripts contain Windows-specific absolute paths (Vina binary,
  `docking_files/`); edit the path constants at the top of each script for your
  platform. Vina 1.2.7 with exhaustiveness 8, seed 42 was used.
- SwissDock AC/EADock runs were submitted manually through the web interface
  (the server does not allow automated jobs) and parsed locally.

## Environment

- R 4.3.3: Seurat 5.x, harmony, monocle (DDRTree), scTenifoldNet/scTenifoldKnk
  1.0.3, clusterProfiler, rhdf5, Matrix, dplyr.
- Python 3.x (scripts 20-30): pandas, numpy; AutoDock Vina 1.2.7 binary;
  Open Babel 3.1.0.
- Run order: `Rscript scripts/build_s01_s02.R` -> `91_candidate_genes.R` ->
  `94_run_s04_full.R` -> `95_consensus.R` -> `s07_oa_validation.R` ->
  docking chain -> figure scripts. `scripts/run_pipeline.R` orchestrates the
  numbered R steps.
